SK hynix Pushes AI Memory Beyond HBM With Rack-Level CXL Pools

SK hynix demonstrated its MARS AI rack and CXL memory pooling at Supercomputing 2026, targeting memory efficiency in AI infrastructure.

TTN Research DeskNov 22, 2026 · 12:17 PM EET

SK hynix is expanding its pitch to the artificial-intelligence infrastructure market beyond high-bandwidth memory, demonstrating a rack-level memory architecture designed to make large pools of data easier to share across servers. At Supercomputing 2026, the South Korean company presented its MARS AI system and a set of memory technologies built around Compute Express Link, or CXL. The demonstrations address a growing constraint in AI deployment: keeping processors supplied with the information they need without paying for every byte to sit in the most expensive and fastest memory.

The central idea is to treat memory resources across a rack as a pool rather than as isolated capacity attached to individual machines. In one demonstration, SK hynix combined CXL memory with CXL hybrid memory, which pairs DRAM with solid-state storage, to share a large key-value cache across the rack. A key-value cache stores information from earlier parts of a model’s computation so that it can be reused rather than calculated again. In conversational AI, this can include context from earlier turns and intermediate data needed to generate the next response.

The company’s demonstration stored large volumes of cache data on SSD within the hybrid-memory system and moved selected information into DRAM when it was expected to be needed again. SK hynix said its system used conversation and task history to predict which cache entries should be retrieved. The MARS architecture uses CXL memory pools for cache and token sharing across CPU racks.

This is not a claim that SSD can replace high-bandwidth memory inside an AI accelerator. HBM remains important because GPUs need extremely high bandwidth for active model computations. Instead, the proposed architecture seeks to manage the layers around that fast memory more efficiently. If a system can retain more useful context in a lower-cost tier and retrieve it quickly when needed, operators may be able to serve more requests with a given amount of expensive GPU capacity.

The commercial opportunity is linked to the changing economics of AI inference. Early infrastructure investment focused heavily on training large models, where clusters of accelerators and HBM capacity were critical. As companies deploy assistants and autonomous agents, inference workloads can involve long conversations, repeated tool calls and multiple stages of reasoning. Those workloads generate and reuse more context. Memory capacity, data movement and server utilization can become important determinants of cost per task, not simply the peak computing speed of a GPU.

SK hynix is well positioned to pursue this market because it already has a strong position in high-performance memory. The company reported third-quarter 2026 revenue of 104.6 trillion won and operating profit of 83.3 trillion won, with an operating margin of about 80%. It said HBM4 was expected to become its mainstream product in the fourth quarter and that long-term agreements with 14 major customers covered more than half of its production capacity for 2027 and 2028.

The new demonstrations could broaden the company’s addressable market from supplying memory components to helping design memory systems. That shift may strengthen customer relationships and make SK hynix more involved in the architecture of AI data centres. It also places the company in a competitive field that includes memory suppliers, server makers, accelerator vendors and interconnect developers. Customers will need evidence that pooled memory works reliably at production scale, fits existing software stacks and lowers total system costs.

There are technical and commercial hurdles. CXL-based memory pooling requires compatible processors, switches, firmware and software. Cache prediction must be accurate enough to avoid moving unnecessary data, while storage retrieval must be fast enough not to stall model serving. Data security and isolation also matter when multiple users or services share infrastructure. Operators will compare the full cost of the system, including power, networking and maintenance, rather than the price of memory alone.

The timing is significant because the AI infrastructure market is moving from a race to install accelerators toward a broader effort to improve utilization. If GPU capacity remains expensive or constrained, techniques that reduce idle time and make context reusable can have direct economic value. But adoption will depend on independent performance results and customer deployments, neither of which was established by the exhibition announcement. SK hynix has shown a direction for product development, not yet a proven industry standard.

For investors, the announcement reinforces two connected themes. HBM demand remains a major earnings driver, while the next stage of AI infrastructure could create additional opportunities in memory pooling, high-capacity DRAM, storage and system-level solutions. The most useful milestones to watch are customer validation, production availability, measurable inference-cost savings and whether cloud providers incorporate the architecture into new server designs.
