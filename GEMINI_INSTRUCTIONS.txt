TTN FINANCE — REPOSITORY-LEVEL GEMINI HANDOFF RULES

This file is a general handoff note only. It does not describe any specific article or cover assignment.

For each publication package, follow the GEMINI_INSTRUCTIONS.txt included inside that exact approved ZIP. Never reuse article titles, image directions, slugs, or publication details from an older package.

GEMINI'S ROLE
- Work only with the approved article package supplied by the user.
- Generate or replace only the cover images explicitly requested for that package.
- Preserve every approved article text, title, dek, slug, date, metadata field, canonical URL, internal link, related-reading entry, ticker, and file path.
- Return the complete ZIP package to the user.
- Do not upload, publish, commit, push, or otherwise modify the GitHub repository.

IMAGE RULES
- Generate one separate editorial image per article; never create collages, grids, or contact sheets.
- Use realistic, restrained financial-news editorial photography and natural lighting.
- Preserve the package's required image filenames, formats, dimensions, and directory structure.
- Do not invent logos, labels, headline text, or visual details.

FINAL CHECK
Before returning the ZIP, verify that all required files are present, the approved HTML files are unchanged, and each cover and responsive variant uses the exact filenames specified by the package-specific instructions.
